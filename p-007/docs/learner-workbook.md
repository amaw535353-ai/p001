# Independent learner workbook — questions only

G1 — Guided understanding: NOT DEMONSTRATED.
Explain how a test-case schema, control requirement, target operation, authorization
class, runner result and evidence artifact are linked. Which oracle observations
can establish server-side enforcement? Which claims remain hypotheses?

G2 — Independent reproduction: NOT DEMONSTRATED.
Choose a baseline and tests without relying on generated step-by-step instructions.
Reproduce them, independently verify hashes and explain any environmental difference.
How would you detect an incorrect oracle even when the evidence hashes match?

G3 — Unfamiliar target: NOT DEMONSTRATED.
Design a reviewed adapter for a modified or unfamiliar local application. Establish
new ownership/scope, create positive and negative tests, and challenge one incorrect
expectation. What prevents a discovered endpoint from becoming automatic authority?

G4 — Consultancy delivery: NOT DEMONSTRATED.
Independently present a remediation retest and a regression, defend comparability,
distinguish observations from confirmed vulnerabilities, and explain residual risk.
What evidence would justify human-reproduced or externally-reviewed provenance?

Do not fill independent-human labels with generated answers or inferred competence.
