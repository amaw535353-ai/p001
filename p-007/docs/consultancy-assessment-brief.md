# Consultancy assessment brief

This is a synthetic laboratory framework for demonstrating positive/negative
security control tests, remediation retesting and reproducible evidence. The
assessor must independently establish legal scope, inspect the real target, justify
oracles, challenge generated hypotheses and assess false positives and residual risk.

Deliver the exact target/plan/fixture/tool identities, normalized per-test results,
baseline/retest differences, sanitized evidence hashes, incomplete/unsupported gates
and limitations. A finite local simulator suite is not broad jailbreak resistance,
a ZAP alert is not a confirmed vulnerability, and a generated report is not a real
client engagement or proof of learner competence. P006 is unavailable here.

Human review should verify scope, behavior evidence, comparability, genuine
remediation provenance and reproduction before any consultancy conclusion. The
questions-only workbook deliberately leaves these independent judgments to the learner.
