# Test methodology

The offline pytest suite runs with IP sockets and DNS denied. It includes
actual sibling examples and schema validation, synthetic source-byte
tamper cases, state-machine tests, privacy canaries, official OSCAL
schema checks, deterministic report reproduction and API doubles.
Redmine has an independent native profile using the pinned 7.0.3 image.
Its product checks measure the real issue API and direct privilege
denial. Review-ready and blocked outcomes remain visible in the demo.
Product claims use native or contract evidence as appropriate.
