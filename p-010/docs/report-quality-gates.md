# Report quality gates

The builder emits 25 identified checks. G01–G04 evaluate scope and
applicability. G05–G12 check reviewers, exact evidence, severity,
reproduction and impact. G13–G18 check remediation, retest, residual
risk and framework claims. G19–G25 check disclosure, authorship,
independent review, placeholders, source preservation, privacy and
local integrity.

An initial draft may be previewed with open gates. REVIEW_READY requires
content gates. Approval additionally validates exact report version,
independent review, non-simulated decisions, current source versions
and current owner decisions. The application cannot substantiate an
author's external factual claims by inspecting prose. The reviewer
evaluates claims against the linked records.
