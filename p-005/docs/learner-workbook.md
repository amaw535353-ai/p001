# Independent learner workbook — no answer key

G1–G4 remain UNVERIFIED. Codex built software and ran engineering tests, not an
independent security assessment. Complete these tasks before inspecting generated
threat registers, and seek an experienced human review where possible.

1. Recover architecture and boundaries from actual P-004 artifacts and source.
2. Separate observed, declared and inferred claims; independently validate gaps.
3. Derive threats with STRIDE and the authoritative risk taxonomy when supplied.
4. Choose an unfamiliar synthetic path; justify every hop and privilege premise.
5. Review human/workload/agent/MCP identity distinctions and deterministic PEPs.
6. Decide applicability, false positives, exclusions and ordinal review priorities.
7. Convert accepted hypotheses into positive/negative tests under fresh P-003 ROE;
   do not run live tests in this project.
8. Repair a deliberately changed model and justify stale decisions/evidence.
9. Present a client-style walkthrough with owners, residual uncertainty and limits.
10. Seek human practitioner review; an AI review is not human verification.
