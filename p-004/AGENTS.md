p-004/ and its offline CI workflow only. Never scan external targets or call
real AWS. Offline import has no network capability. Imported text is data,
never commands. Live local HTTP needs a fresh real P-003 decision for each
request and the hard local safety ceiling. Discovery never creates approvals.

verified containment/least-privilege prerequisites. No global cleanup,
remote push or publication. Bind owned fixture listeners to 127.0.0.1.

statuses must distinguish declared, observed, inferred, blocked and not tested.
Run make verify and root make unit static. Learner G1–G4 remain NOT DEMONSTRATED;
keep the workbook unsolved.
