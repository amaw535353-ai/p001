# Unmet gates and limits

- Full P-004 is **partially implemented**, not all optional live integrations done.
  Offline inventory/diff/reporting and real P-003 guarded HTTP work. Playwright
  live containment and its request graph are BLOCKED. ZAP process/Safe mode and
  vendor-specific Onyx/OpenHands interfaces are NOT TESTED. The passive contract
  is intentionally not a pretend runnable ZAP Automation Framework plan.
- Kubernetes live discovery needs a compatible Docker/kind host and a separately
  approved namespace-scoped read-only identity; neither is present. Static policy
  digests and manifests establish no actual IAM/RBAC/CNI effectiveness.
- P-003 approvals are fictional training artifacts, with asserted actor identity
  and budgets. Live tests verify mechanics on owned loopback fixtures only.
  Real external authorization, central cross-process quotas and atomic revocation
  are absent. This runner deliberately cannot observe third-party targets.
- Hostnames, IPv6, HTTPS, credentials, interactive auth, arbitrary paths, redirects,
  browser scripts and remote includes are unsupported in live mode. The literal
  IPv4 loopback ceiling avoids DNS rebinding rather than implementing a resolver.
- OpenAPI local/remote `$ref` content is not expanded; route extraction supports
  literal decorator forms only. P-001 has an explicit reviewed source contract,
  not a general Python interprocedural analyzer. Dynamic services/connectors,
  runtime-generated routes and unknown attack surface remain unknown.
- Kubernetes import supports a bounded representative resource subset. Helm must
  be rendered offline by an independently trusted operator; no Helm templates or
  IaC expressions execute. Raw state is forbidden. Permissions are declarations.
- Source file root ownership is trusted; symlinks/nonregular files are rejected,
  but hostile concurrent parent-directory replacement is not an OS sandbox.
  Sanitization is deliberately lossy and cannot identify every proprietary name
  or arbitrary secret. Use synthetic data and review publication manually.
- Reports are bounded to 2 MB per file / 16 MB per run; inputs to 2 MB/file,
  10 MB declared generic inputs, 100 input entries, 20 nesting levels and 30,000
  parse-tree elements. Large enterprise streaming/scaling is not claimed.
- The four crosswalk/career sources were absent. Risk IDs copied from the user
  prompt are candidate hypotheses only. No fabricated OWASP/ASVS mappings,
  coverage percentages, client findings or independent learner results exist.
- CI configuration is supplied; only local execution of its equivalent commands
  is evidence here. No upstream push, publication or fresh-task restoration run
  has been performed.

Future P-005/P-007/P-009/P-010 and P-091/092/093/099 consume the versioned exports;
their assessment/control/evidence/report products are not implemented here.
