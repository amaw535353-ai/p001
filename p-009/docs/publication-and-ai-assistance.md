# Publication and provenance

Codex implemented and tested this synthetic local project. Human independent reproduction and
external human verification are NOT DEMONSTRATED. Learner G1–G5 remain unverified. No real client
incident, vulnerability finding, provider security assessment or production certification is claimed.

The direct user request explicitly authorizes commit, push and merge of P009 source. The uploaded
document is the build specification; its default no-publication clause does not override that
separate direct authorization. Runtime telemetry, secrets, databases, native logs, generated evidence,
tools and local exports remain ignored. Publishing source does not publish a running lab or its data.

Upstream licenses and image/software provenance require independent review before redistribution
or client use. Exact hashes identify reviewed artifacts; they are not proof of vulnerability freedom.
