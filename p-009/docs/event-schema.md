# Versioned event model

`p009-event-1.0` is generated from frozen Pydantic models into strict JSON Schema. Required
source/event identity, UTC event time, observed time, trusted tenant/actor/service identity,
normalized-source digest, redaction policy and provenance accompany every retained event.
Trace/span IDs have exact hexadecimal widths and reject all-zero values. Unknown critical
fields fail validation; collection adapters first omit explicitly non-permitted content.

Request/session/conversation/tool/authorization/test/run/alert/artifact identifiers are optional
when absent at source. No ID is synthesized to fill a correlation gap. Event IDs identify a source
record; generating a new synthetic event ID is different from inventing a missing source request ID.
Severity is derived from controlled decisions/rules, never accepted from arbitrary payload labels.

`source_event_digest` hashes canonical metadata. Source raw text is deliberately absent. JSON
duplicate keys, non-finite numbers, oversized files, invalid UTC and unsupported enum values fail.
Schemas are regenerated by `scripts/build-schemas.py`; `--check` detects drift.
