# Engineering evidence

SYNTHETIC TRAINING ENGAGEMENT — NOT AUTHORIZATION FOR REAL-WORLD TESTING

Actual run manifests and current JUnit reports are created here and ignored by Git.
They record command, working directory, exit status, bounded sanitized excerpts,
tool/code versions and hashes. These are builder observations, not human assessment.
`scripts/verify.sh` and `scripts/demo-workflow.py` produce fresh, uniquely named runs.
No raw client evidence, authentication token or real reviewer identity belongs here.
Hash-linked local records are not independent notarization. The committed engineering
results document points to the actual run and its file digest.
