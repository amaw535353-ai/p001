# What P-003 establishes

SYNTHETIC TRAINING ENGAGEMENT — NOT AUTHORIZATION FOR REAL-WORLD TESTING

| Subject | Mechanically enforced | Policy/model claims or human prerequisites |
|---|---|---|
| Version and scope | Exact digests, allowlist, exclusions, fresh review | Human must decide appropriate scope |
| Workflow | Separate actor labels, allowed transitions, serialized stops | Labels are not authenticated humans |
| Authorization evidence | Presence, schema, fictional reviewer binding, byte hash | Authentic client permission and legal standing NOT VERIFIED |
| Windows | UTC boundaries and supplied request time | Trusted wall clock and runner timing NOT VERIFIED |
| Limits | Supplied counters compared with all ceilings | Actual usage, rate and impact telemetry NOT VERIFIED |
| Targets | Conservative offline canonicalization, local identifiers | Actual ownership, DNS, rebinding and upstream terms NOT VERIFIED |
| Evidence | Synthetic schema, known-secret pattern gate, hashes | Completeness of redaction/real PII detection NOT VERIFIED |
| Audit | Append-only triggers, sequence/hash/role checks, local transaction | Database-owner tampering or external notarization NOT VERIFIED |
| Integrations | Proposals only, owned local Redmine checks | Runtime controls and external tool enforcement NOT VERIFIED |

No real-client, outbound assessment, scanner invocation, legal e-signature,
identity provider, HSM/signing infrastructure, authentication API, certificate,
assessment-results/POA&M/FedRAMP or authorization-to-operate functionality is supplied.
Real authority requires authentic client permission, a verified representative,
agreed ROE, law/contract review, actual ownership and provider constraints. Do not
reuse a demo review, document, CLI actor reference or export as that proof.

A caller can replay exported files or ignore a DENY outside this process. Decisions
are point-in-time, never transferable bearer capabilities. The local store must be
rechecked before each future action; safety at the execution tool remains separate.
